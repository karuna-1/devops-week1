# Day 5 — Git & GitHub

## What I Learned

Today I learned how Git works with GitHub, including clone, fetch, pull, push, .gitignore, branches, and Pull Requests.

## Git & GitHub Commands

- `git clone` — downloads an existing repository to the computer.
- `git fetch` — downloads information about remote changes without changing working files.
- `git pull` — gets remote changes and integrates them into the local branch.
- `git push` — sends local commits to the remote repository.
- `.gitignore` — tells Git which files or folders should not be tracked.

## Pull Requests

A Pull Request is a request to merge changes from one branch into another, usually after review.

## Feature Branch Workflow

Working branch → commit → push → Pull Request → review → merge → main

## Day 5 Practical
